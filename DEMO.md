# Demo script — about 2 minutes

Sample contract to paste (fake, for demo only):

"Freelance design agreement between Ada (designer) and Bright Ltd (client). Fee: $200, paid 60 days after delivery. Designer gives up all IP on payment. Client may end the agreement at any time with no notice. Designer must fix all issues for free for 12 months. Work starts 20 Nov 2026."

1. (10s) "Freelancers sign contracts alone. This reads one first, and shows its working."
2. (20s) Paste the sample contract above. Click Review this contract.
3. (50s) Read the summary out loud, then payment, then each risk: 60 day pay, IP grab, end at any time, 12 months free fixes. Then each reasoning step on screen, one by one.
4. (20s) "It runs on SERV Reasoning, with an open model. Every answer shows its steps, so you can audit it instead of trusting it."
5. (20s) "General information only, not legal advice. The contract is sent for review only. It is not stored."

Record while SERV credits last. If the key runs out mid-demo, the error message and the recorded run still show the flow.
